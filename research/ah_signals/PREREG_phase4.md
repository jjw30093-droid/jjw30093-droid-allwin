## 2. 共同定义

| 项 | 定义 |
|---|---|
| 收盘 snap(主) | 各公司各市场:`observed_at ≤ kickoff−10min` 的最后一条;距 kickoff >120min 记缺失(同 PREREG §0) |
| T-24h snap | `observed_at ≤ kickoff−24h` 的最后一条;首条晚于 kickoff−24h 记缺失(25/26 Crown AH 缺 0) |
| T-60min snap | `observed_at ≤ kickoff−60min` 的最后一条(只用于 M6 的描述性相关) |
| 开盘 | payload `initial`(两季恒定,Phase 1b) |
| 档 | 0.25 球 = 1 档;线变 = (后 − 前)/0.25,**正值 = 向主队方向移动(主让加深 / 客让变浅)** |
| 水位 → 隐含概率 | NowGoal AH/OU 水位是港式赔率(净利/本金):`p_raw = 1/(1+w)`;去水 `p_home = p_raw_home/(p_raw_home+p_raw_away)`(OU 同理 over/under)。1x2 是欧赔:`p_raw = 1/odds`,三项归一 |
| 水位合理性 | 沿用 PREREG §6.3:`home+away ∉ [1.60,2.10]` 或单边 `<0.30` 的 snap 记异常、不参与取点 |
| ±15 分钟同时刻 | 两个(或三个)snap 的 `observed_at` 两两相差 ≤15 分钟;否则该特征缺失 |
| Bet365 剔除 | `BET365_EXCLUDE_MIDS`(5868027,26/27,本阶段不在样本内,规则仍保留) |

**覆盖概率(模型侧)统一用 EV 中性公式**,不再用"近似":
`p_eff = (Wf + Wh/2) / (Wf + Wh/2 + Lf + Lh/2)`,其中 Wf/Wh/Lh/Lf 分别为全赢/赢半/输半/
全输的概率(按 AH 规则由比分分布算出);整数盘的走水(push)自动被排除在分母外。M3、M4b、
M5 中凡是模型侧的覆盖概率一律用它。市场侧的去水概率保持 `1/(1+w)` 归一。

### 2.1 水位格式核验(运行 Phase 4 前必须做;只看赔率本身,不看结果)

- 对 Crown、Bet365 的 AH、OU,以及 Bet365 的 1x2,分别统计 25/26 收盘 snap(主定义)的原始
  水位分布(p1/p50/p99)。
- 按港式假设计算两边隐含概率之和 `1/(1+w_home) + 1/(1+w_away)`(OU 同理;1x2 用
  `Σ 1/odds`),报告其分布(p1/p50/p99 及落在各区间的比例)。
- 判定标准:**p50 ∈ [1.02, 1.08] 且 99% 的 snap ∈ [1.00, 1.15]**。不满足的公司或市场,
  停下报告,不进入 Phase 4 计算。
- 结论写进 `docs/data-sources.md`。

## 3. M 市场族(主检验 `margin ~ closing_line + feature`;独立 BH,q=0.10;共 7 个检验)

`margin`、`closing_line` 均为 Crown 主定义。方向 = 控制收盘线后系数的预期符号。

| # | 特征 | 构造 | 缺失规则 | 预期方向 | 理由 |
|---|---|---|---|---|---|
| M1 | 开盘→收盘线变 | `(close_line − initial_line)/0.25` | 无 initial 或无收盘 → 缺失 | 双侧 | "跟随热钱"(+)与"市场过度反应"(−)两个假设都存在;本会话早期的临时分析(有前视偏差,已作废)未见可交易的边际,不预设方向 |
| M2 | T-24h→收盘线变 | `(close_line − line_T24)/0.25` | 无 T-24h → 缺失 | 双侧 | 同 M1,时窗更近 |
| M3 | 同线水位移动(隐含概率变化) | 若 `line_T24 == close_line`:`Δp = p_home_close − p_home_T24`(去水);若线变:`Δp = 0`;另设指示 `I_move = 1[line 变动]` 作为协变量一起进回归(`margin ~ closing_line + Δp + I_move`),只对 Δp 做检验 | 无 T-24h → 缺失;任一 snap 水位异常 → 缺失 | **+** | 线不动时资金压力体现在水位;方向同 M1 |
| M4a | Crown↔Bet365 收盘线差 | `(crown_close_line − b365_close_line)/0.25` | 两家收盘 snap 相差 >15 分钟 → 缺失;Bet365 缺收盘 → 缺失 | 双侧 | 哪家更 sharp 无先验;若 Bet365 更 sharp,系数应为负(Bet365 更看好主队时 Crown 的线偏低) |
| M4b | 同线隐含概率差 | 仅 `M4a == 0` 的场次:`p_home_crown − p_home_b365`(去水);线不同 → 缺失 | 同上 + 水位异常 → 缺失 | 双侧 | 同 M4a |
| M5 | Bet365 内部一致性(AH+OU Poisson vs 1x2) | 见 §3.1;**检验模型为 `margin ~ closing_line + closing_line² + M5`**(吸收独立 Poisson 低估平局带来的非线性偏差);另报 M5 对 closing_line 的分箱均值(描述性) | Bet365 AH/OU/1x2 三个收盘 snap 两两 >15 分钟 → 缺失;任一市场缺收盘 → 缺失;Poisson 拟合不收敛 → 缺失 | 双侧 | AH/OU 与 1x2 谁更 sharp 无先验;差值只是"同一公司两套市场的不一致" |
| M6 | 阵容意外 | `mean_rr(本场实际首发 11 人) − mean_rr(上一场首发 11 人)`;`rr` = 球员赛前滚动评分(PREREG C9 定义:只用 kickoff 严格早于本场的比赛的赛后 rating,分钟加权 EWMA8,≥3 场);两组各需 ≥8 名有效球员,否则缺失 | 缺 lineup / 有效球员 <8 → 缺失 | **+** | 实际首发比预期强 → 若收盘线未充分反应则主队更易赢盘 |

M3 的 `I_move` 与 M4b 的"仅同线场次"都不是独立检验,不计入 BH 分母。M 族 BH 分母 = 7
(M1、M2、M3、M4a、M4b、M5、M6);若某特征因缺失率 >50% 无法可靠估计,移出并按剩余数
计算,移出只看缺失率不看结果。

### 3.1 M5 的 Poisson 反推(写死)

- 输入:Bet365 收盘 AH(线 L,去水 `p_ah_home`)、OU(线 T,去水 `p_over`)、1x2(去水
  `p_1x2_home`),三者 `observed_at` 两两 ≤15 分钟。
- 模型:主客进球独立 Poisson(λ_h, λ_a),不做 Dixon-Coles 修正,比分截断 0–10。
- 求解:在网格 λ_h, λ_a ∈ [0.10, 4.00] 步长 0.01 上最小化
  `(P_model(主队覆盖 L) − p_ah_home)² + (P_model(总进球 > T) − p_over)²`,
  其中 `P_model(主队覆盖 L)` 用 §2 的 EV 中性公式 `p_eff`(四分之一盘拆两半仓分别算
  Wf/Wh/Lh/Lf;整数盘 push 自动排除),OU 同构(over 全赢/半赢/输半/全输)。
- `M5 = P_model(home−away > 0) − p_1x2_home`。
- 检验:`margin ~ closing_line + closing_line² + M5`,对 M5 做检验;描述性:按 closing_line
  分箱(每 0.25 档一箱,N<30 的箱合并到相邻箱)报告 M5 的均值 ±95% CI。
- 拟合残差 >0.02(任一项)的场次记"拟合不佳",报告条数;仍保留进检验。

### 3.2 M6 的描述性补充(不进 FDR)

- `Δline_60 = (close_line − line_T60)/0.25`(Crown;`line_T60` = kickoff−60min 前最后一条
  Crown AH snap 的线,即 `observed_at ≤ kickoff−60min` 的最后一条);报告 `corr(M6, Δline_60)` 与 N,以及
  M6 分三档(<−0.1 / −0.1~0.1 / >0.1)的 `Δline_60` 均值 ±95% CI——衡量市场对阵容意外的
  反应程度。只描述,不检验。
- 实际首发来自 `fact_match_lineup.is_starter`——**这是赛后记录**,作为"kickoff−60min 公布
  名单"的代理;两者只在热身受伤等极少情况下不同,报告里注明这是代理。

## 4. T 时点族(新目标;独立 BH,q=0.10;注明"Phase 3 结果已知,但目标变量不同")

对 PREREG C 族 **11 个**特征(C1、C2、C3、C5、C6、C7、C8、C9、C10、C11、C12,主版本
8 场窗口 diff),用 T-24h Crown 线作控制:

| 子族 | 目标 | 回归 | 预期方向 |
|---|---|---|---|
| T-a | `margin_T24 = (home−away) − line_T24` | `margin_T24 ~ line_T24 + feature` | 同 PREREG §3.5 各特征的方向 |
| T-b | `Δline = (close_line − line_T24)/0.25` | `Δline ~ line_T24 + feature` | 同上(特征利好主队 → 线向主队移动) |

- **恒等式**:按库内符号规则(`line>0` = 主让,`margin = (home−away) − line`),
  `margin_T24 = margin + Δline_raw`,其中 `Δline_raw = closing_line − line_T24`(球;
  `Δline = Δline_raw/0.25` 档)。运行时逐场数值验证,贴出不成立的场次数(应为 0)。
- T-a 与 T-b **各自独立做 BH(分母各 11)**(站长审定)。
- T-b 通过 BH 的特征,额外做描述性报告(不进 FDR,不构成结论):按 T-b 系数符号在 T-24h
  线与水位上平注(特征 diff × sign(系数) >0 → 押主,<0 → 押客,=0 不押),报告 N、命中率、
  ROI ±95% CI(按 T-24h 时刻真实水位、以 T-24h 线结算)与 CLV。**CLV 定义(写死)**:
  - `CLV_line` = 下注方向上的有利线变,单位 0.25 档,有利为正(押主:`(closing_line −
    line_T24)/0.25`;押客:取负);
  - `CLV_p` = T-24h 与收盘**同线**时,下注方向去水概率的变化(收盘 − T-24h);
  - 线有变动的场次只报告 `CLV_line`;同线场次两项都报告。
- 25/26 T-24h Crown 缺失为 0(Phase 1),N 应与 Phase 3 相同;实际 N 以输出为准。

## 6. 截断测试

所有 M 族特征(M1–M6、`I_move`、`Δline_60`)与 T 族目标/控制项一并纳入截断测试:按比赛日
分组、全量档、删除开球日 > 该日的全部比赛(含赔率快照、阵容、球员行)后重算,逐字段浮点
严格相等(`==`)。M 族只依赖本场赛前快照与严格更早的比赛,预期全部相等;不等即停。
预计耗时与 Phase 2 同量级(≈8 分钟),运行前后贴 `free -m`/`uptime`。

## 7. 功效

按各特征实际 N、25/26 `margin` SD(1.539;T-b 目标用 `Δline` 自身 SD)重算:
`r_min = (z_{α/2} + z_{0.80})/√N`,α 取 0.05 与各族 BH 最严档(M:0.10/7;T-a、T-b:0.10/11),
折算成"目标单位/SD"。

## 8. 报告项(每个特征)

系数、HC1 SE、t、p、q、与控制项(`closing_line` 或 `line_T24`)的相关系数、5 条稳健性条件
逐条、方向是否与预期一致、不显著时的效应上限(95% CI 绝对值上界,折算成目标单位/SD)。
p 值正态近似(df≈1600),OLS+HC1 纯 Python 实现(已与 numpy 核对)。
