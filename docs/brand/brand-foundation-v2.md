# 欧赢 ALLWIN 品牌基础 V2

更新日期：2026-07-29

## 1. 本轮判断

V1 的品牌语言保留，但“超大口号 + 方法宣言卡 + 装饰图形”的首页结构停止使用。
这类结构更像一份生成式品牌提案，不像每天会有人打开的足球数据产品。

V2 的首页原则是：

```text
比赛先出现，品牌后解释。
真实内容证明专业，口号不承担证明任务。
```

## 2. 保留的品牌语言

```text
欧赢 ALLWIN
足球数据与比赛分析

看数据，也看门道。

赛程、状态、xG、赔率变化和历史记录，
一场一场看，一条一条说。

数据有出处，判断有记录。
```

口号只用于导航品牌说明、栏目引言和传播落款，不再占据整屏。

## 3. 产品首页结构

首页面向以手机访问为主、希望快速看到当日比赛信息的足球用户。首屏不得承担
平台介绍或合作说明，固定按以下顺序组织：

1. 今日重点比赛名称、时间与数据更新状态；
2. 真实横版/竖版比赛数据图卡；
3. “查看完整分析”和“更多比赛”两个动作；
4. 近期赛程与最近完赛；
5. 公开记录、会员权益、关于我们的轻量入口。

平台是谁、数据方法、内容工作流、合作方向和公众号联系方式统一进入
`/about`；详细模型口径继续由 `/about-model` 承担。首页不使用没有数据支撑的
“行业领先”“智能洞察”或虚构内容卡。

移动端导航只保留比赛、会员和关于我们；Logo 本身承担首页入口。分析员和管理
入口不在手机主导航中占位。

## 4. 视觉系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 深海蓝 | `#0D2C3D` | 主文字、导航和高对比表面 |
| 赛场青 | `#087E78` | 数据状态、链接、栏目编号 |
| 荧光黄 | `#D7ED63` | 少量运行状态和流程节点 |
| 雾灰 | `#F4F6F6` | 页面背景 |
| 白 | `#FFFFFF` | 数据面板 |

视觉约束：

- 比赛列表、时间、来源和状态优先；
- 小圆角、薄边框、无悬浮阴影；
- 不使用抽象圆环、HUD、渐变光晕或装饰性百分比；
- 标题保持正常产品字号，不做海报式断句；
- 色彩只承担导航、状态和信息分组。

## 5. 外部参考的取舍

- Opta Analyst：借鉴“最新内容先出现”和栏目化编辑结构，不复制其媒体站版式；
- Hudl StatsBomb：借鉴“用真实数据规模、模型与工作流证明能力”，不使用空洞宣言；
- FotMob / Sofascore：借鉴“今日比赛与状态过滤先于品牌介绍”的产品顺序；
- FBref：借鉴数据密度和直接性，不照搬其桌面表格密度。

外部参考只用于结构原则，不复制商标、配色、组件或文案。

## 6. 当前落地

V2 已更新：

- 全局产品色和表面变量；
- 顶部品牌锁定与选中状态；
- 首页“重点比赛 → 数据图卡 → 近期比赛”的移动端优先顺序；
- 独立“关于我们”页面与合作入口；
- 比赛行、指标、套餐与 Studio 工作流表达。

后续应按相同原则继续打磨比赛详情页、联赛页、定价页与 Studio 导出模板。
