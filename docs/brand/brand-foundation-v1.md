# 欧赢 ALLWIN 品牌基础 V1

更新日期：2026-07-29

## 1. 品牌定位

```text
欧赢 ALLWIN
足球数据与比赛分析
```

欧赢把赛程、状态、xG、赔率变化和历史记录整理成中文用户看得懂、能继续讨论的
比赛分析。品牌不使用“AI 引擎”“胜负密码”“精准命中”等夸大或机器化表达。

## 2. 品牌语言

主口号：

```text
看数据，也看门道。
```

辅助文案：

```text
赛程、状态、xG、赔率变化和历史记录，
一场一场看，一条一条说。
```

信任表达：

```text
数据有出处，判断有记录。
```

主要行动文案：

- 看今日比赛
- 查看公开记录

“开赛前，把一场比赛讲清楚”可用于品牌介绍或专题文章，不再作为全站主口号。

## 3. 视觉系统

第一版采用“朱砂红线”的中文编辑部方向：

| 角色 | 色值 | 用途 |
|---|---|---|
| 朱砂红 | `#E6432F` | 品牌识别、重点结论、栏目索引 |
| 深朱砂 | `#B92E22` | 小字号链接和数字，保证可读性 |
| 冰蓝 | `#C9E5ED` | 数据批注、选区和辅助信息 |
| 暖纸白 | `#F3EFE5` | 页面底色 |
| 明纸白 | `#FFFDF7` | 卡片与正文表面 |
| 煤黑 | `#151616` | 正文、按钮和高对比信息 |

视觉原则：

- 像一份懂球的人做的比赛读本，不像 AI 控制台。
- 使用编辑网格、栏目短线、真实时间和真实数据，不使用虚构百分比装饰。
- 不使用雷达 HUD、紫蓝霓虹、机器人、金币、皇冠、盾牌或“上涨箭头”。
- 标题大而直接，正文保持克制；动画只服务状态变化，不制造科技感。
- 品牌锁定以“红线 + 欧赢 ALLWIN”文字为主，正式独立图形标志留待后续专项设计。

## 4. 文案边界

推荐使用：

- 看、查、说、记录、变化、截至、公开
- “系统于……检测到”
- “市场去水基线”
- “数据有出处，判断有记录”

避免使用：

- AI 洞察、智能引擎、赋能、胜负密码
- 必胜、稳赚、红单、连红、精准命中
- 将同期事件写成赔率变化的原因

## 5. 当前落地范围

V1 已应用于：

- 全站颜色和表面变量；
- 顶部品牌锁定与主导航；
- 首页首屏、主口号、辅助文案与行动按钮；
- 首页栏目标题、卡片、套餐和比赛行基础样式；
- 网站标题与描述元数据。

比赛详情、联赛页、定价页、Studio 导出模板、专题页和社交媒体模板将在后续
模块中按同一系统逐步迁移。
